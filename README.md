## 📌 Overview

AI Mental Health Chatbot is an intelligent and interactive mental wellness assistant designed to provide users with emotional support through AI-powered conversations.

The chatbot analyzes user emotions using sentiment analysis, tracks mood patterns over time, and suggests personalized coping strategies to encourage mental well-being.

This project combines Natural Language Processing (NLP), AI conversation models, and data visualization into a simple and user-friendly web application.

# ✨ Features

✅ AI-powered chatbot using Ollama
